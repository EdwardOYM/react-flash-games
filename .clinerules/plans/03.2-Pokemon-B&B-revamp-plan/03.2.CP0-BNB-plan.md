# 03.2.CP0 — B&B Revamp Audit and Activation

> Parent: `03.2-Pokemon-B&B-revamp-plan.md`. Completed on 2026-09-25.

## Scope

Lock the five source rules: `actions-per-turn.md`, `between-turns.md`, `board-state.md`,
`pokemon-ability-and-attacks.md`, and `start-of-game.md`. Preserve these decisions for all later CPs:

- exactly 40 cards, including Energy;
- opened non-Energy cards plus unlimited available basic Energy construction;
- Prize cards configurable 4 or 6, default 4, separate from the 40-card construction total;
- exact Draw → Main → Attack/Pass → Between-Turns flow;
- mirrored board and PackStack reveal.

## Audit result

The current engine/protocol/UI still uses minimum-size deck legality, 2–6 Prize settings, automatic
setup, coarse phases, no Basic-to-Bench/Tool/Ability/Pass actions, no once-per-side Retreat guard,
single pending promotion, per-player Checkup iteration, Energy-only attachments, and a non-PackStack
B&B reveal. The 30C card data contains real ability text but only partial effect coverage. Unsupported
text must be recorded and never guessed.
