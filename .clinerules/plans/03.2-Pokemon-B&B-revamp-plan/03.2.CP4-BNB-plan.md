# 03.2.CP4 — B&B Turn Phases, Actions, and Between-Turns

> Parent: `03.2-Pokemon-B&B-revamp-plan.md`. Depends on CP3.

## Scope

Implement the supplied `Draw → Main → Attack/Pass → Between-Turns` sequence. Draw resets limits,
draws one, and settles deck-out before Main. Main actions are any-order: Basic-to-Bench, evolution, Item,
Tool, and eligible during-turn Ability; once-per-turn Energy, Supporter, Stadium, and Retreat. Enforce
first-turn restrictions, same-name Stadium rejection, exact retreat payment/once-per-side limit, and
Asleep/Paralyzed attack/retreat blocks. Add explicit Pass as the non-attack end-turn action.

Rewrite Checkup as global Poison → Burn → Asleep → Paralysis resolution, then between-turn effects, then
all KOs/prizes. Replace single promotion state with an ordered queue for simultaneous KOs, next player first.

## Files

Engine types/actions/turns/effects/helpers, action controls, locales.

## Validation

Draw/deck-out, out-of-phase rejection, any-order Main actions, every limit, first-turn restrictions,
Retreat/Pass, ordered status trace, simultaneous KO promotion, snapshots, build + lint.
