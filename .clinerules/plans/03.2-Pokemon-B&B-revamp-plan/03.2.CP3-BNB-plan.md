# 03.2.CP3 — B&B Explicit Setup and Start-of-Game Flow

> Parent: `03.2-Pokemon-B&B-revamp-plan.md`. Depends on CP2.

## Scope

Replace automatic setup with an explicit, private, deterministic flow:

1. shuffle the 40-card deck;
2. flip the opening coin before hand reveal;
3. choose first/second;
4. draw seven;
5. Mulligan until a Basic exists, recording the opponent’s extra-card penalty;
6. each side explicitly chooses one Basic Active and up to five Basic Bench Pokémon;
7. set the configured 4 or 6 Prize cards from the deck;
8. reveal Active/Bench simultaneously;
9. begin the first player’s Draw Phase.

Add setup phase/readiness and typed setup actions to the pure engine. Keep opponent hand, deck, and
Prize contents private in snapshots. Prize setup must use the configured value without changing the
40-card submitted deck.

## Files

Engine `types`, `constants`, `setup`, `actions`, `helpers`, `snapshots`; `PokemonBnbGame.tsx`; locales.

## Validation

Same-seed determinism, both first-player choices, Mulligan/penalty, invalid Active/Bench choices, 0–5
Bench capacity, simultaneous reveal, 4/6 Prize setup, host-authoritative guest setup, snapshot privacy,
build + lint.
