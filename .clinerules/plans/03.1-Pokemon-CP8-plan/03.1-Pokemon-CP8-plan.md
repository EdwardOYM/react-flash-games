## CP8-B — Action driver (only `PokemonBnbGame.tsx`)

### TASK B-1 — `runBattleAction(actor, action)`

- Inputs: `battle/setBattle`, `battleError/setBattleError`, `processAction`, types `PlayerSlot`, `BattleAction`.
- Logic:
  1. Add `const runBattleAction = (actor, action): boolean` beside `runLocalAction`.
  2. Guards: `!battle -> false`; `battle.over -> setBattleError('match-over'), false`; `battle.viewOnly -> setBattleError('view-only'), false`.
  3. `const result = processAction(battle, actor, action)`; `setBattle(result.state)` always; `setBattleError(result.error ?? null)`; return `result.error == null`.
  4. Real play actor = `mySlot` from `roleRef` (host/guest); localMode passes seat. No networking (CP9).
- Do NOT: add selection, change render/CSS/locales.

### TASK B-2 — Selection state (state only)

- Inputs: `useState`; keys used later only.
- Logic:
  1. Add `selHand/selBench/selAttack: number | null` + `clearBattleSelection()`.
  2. `resetMatchStateRef` impl also clears all three + `setBattleError(null)`.
  3. `runBattleAction` success path calls `clearBattleSelection()`; failure keeps it.
- Do NOT: render UI yet.
### TASK B-3 — Harness reuses driver

- File: `src/games/pokemon-bnb/PokemonBnbGame.tsx` (call-site only).
- Inputs: `runBattleAction` from B-1, `LocalSeatControlsProps { actor, side, promotionPending, onAction }`.
- Logic:
  1. `runLocalAction = (actor, action) => runBattleAction(actor, action)` (delegate) or replace call-sites.
  2. Keep harness button ids technical (dev-only behind `localMode`), do NOT translate.
  3. Verify `pendingPromotion === actor` gates all but `promoteActive` (-> `must-promote`).
- Gates: build + lint clean; `?local=1` still plays full turn.

## CP8-C — Tabletop upgrade (`BattlePanel` in same file)

### TASK C-1 — Active face with counters

- Inputs: new props `rarityLabelFor: (rarity: CardRarity) => string`, `faceDownLabel: string`; parent has `rarityLabel()` + `t('pokemonBnb.cardFaceDown')`.
- Logic:
  1. Extend `BattlePanelProps` with the two props; pass from `playing` branch.
  2. Active block: `<PokemonCard card={active.card} rarityLabel={rarityLabelFor(active.card.rarity)} damage={active.damage} statuses={STATUS_CONDITIONS.filter(s => active.conditions[s])} />` (raw ids for pips).
  3. Keep `⚡n` chip (`attachedEnergy.length`) + translated condition line (accessible text for pips).
  4. `active == null` keeps `zoneActive: —` placeholder.
- Do NOT: click handlers, header change, CSS.

### TASK C-2 — Bench as selectable buttons (own side)

- Inputs: props `isSelectableBench: boolean`, `selectedBench: number | null`, `onSelectBench?: (i: number | null) => void`; key `selectTarget`.
- Logic:
  1. Replace bench text-join with `<ol className="bnb-bench-list">` of `<button aria-pressed onClick={toggle}>` each with mini `PokemonCard` (damage/statuses) + `⚡n`.
  2. Foe: `isSelectableBench=false`, disabled (or span); names still visible (public zone).
  3. Empty bench -> `—`.
- Do NOT: dispatch actions; new CSS (styled in E).
### TASK C-3 — Own-hand interaction

- Inputs: props `selectedHand`, `onSelectHand`; key `selectHandCard`.
- Logic:
  1. Replace hand spans with `<ol>` of `<button>` toggling `selHand` (aria-pressed + aria-label with card name).
  2. Enabled only when `isSelf && !battle.over`; foe renders nothing (header count only).
  3. Chip shows `card.name` only.
- Do NOT: dispatch from chips (D does that).

### TASK C-4 — Prize/discard counters (display)

- Inputs: `side.prizeCount`, `prizeTotal`, `discard/deck/hand` lengths; keys `zone*`.
- Logic: verify header uses `side.prizeCount` (not prizes.length); optional live region on prize segment.
- Do NOT: render prize faces (face-down by rulebook).

## CP8-D — Controls + overlays (same tsx, view logic)

### TASK D-1 — Turn action bar (own turn)

- Inputs: `battle`, `mySlot` (localMode: activePlayer), `selHand/selBench`, `runBattleAction`; keys `battleActions actionAttach actionPlayTrainer actionEvolve actionRetreat actionAttack actionEndTurn waitingTurn`.
- Logic:
  1. `isMyTurn = !over && pendingPromotion == null && activePlayer === mySlot`; else waiting notice (+ must-promote when gated).
  2. Bar `<div className="bnb-action-bar" role="toolbar">`: Attach (needs selHand -> target selBench or active), Trainer, Evolve, Retreat (needs selBench), Attack (one btn per active attack, verbatim name, fires useAttack), EndTurn (always on).
  3. Disabled: hand actions when selHand null; retreat when selBench null; all when over or gated.
  4. Attack aria = translated prefix + verbatim name.
- Do NOT: P2P send (CP9); new keys.
### TASK D-2 — Promotion picker gate

- Inputs: pendingPromotion, mySlot, selBench, runBattleAction; keys promoteTitle actionPromote.
- Logic: when gated on self show dialog bnb-promote-gate with bench buttons (reuse selBench) + confirm promoteActive; disabled when selBench null. Bar hidden except must-promote notice.
- Do NOT: dismiss without promoting.

### TASK D-3 — Pause overlay (Tron pattern)

- Inputs: view/setView; existing pause/resume/exit/leaveLobby keys only.
- Logic: Pause button in playing topbar (disabled when over) -> paused view with Resume (-> playing) + Leave (-> leaveLobby). Battle untouched. Add comment for CP9 wall-clock.
- Do NOT: timer logic, new keys, engine change.

### TASK D-4 — Help overlay

- Inputs: local helpOpen state (reset in resetMatchState); keys helpTitle helpBody cancel.
- Logic: ? button in topbar; dialog with title + body + Close (autofocus); does not change view.
- Do NOT: per-card rules.
